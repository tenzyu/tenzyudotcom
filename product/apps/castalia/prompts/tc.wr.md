Weekly Recompiler を実行して。

この1週間の GPT 利用・作業・思想・設計を、長期資産として再編成して。

分類:
1. 完了したこと
2. 未完了だが価値があること
3. 捨てるべきもの
4. 繰り返し出てきた問い
5. 新しく生まれた設計原則
6. 既存 Project に反映すべき内容
7. tenzyu.com に公開できる内容
8. GitHub repo に docs として入れる内容
9. 来週の最重要テーマ
10. 来週やらないこと

出力:
- Project 別サマリ
- 資産化リスト
- 公開候補
- 実装候補
- 保留リスト
- 来週の最初の1手
