Session Compiler を実行して。

このスレッドから、再利用価値のあるものだけ抽出して。
一時的な感情、重複、雑談、現在の文脈に依存しすぎるものは捨ててよい。

分類:
1. 設計原則
2. 判断基準
3. 実装ルール
4. コマンド/手順
5. README / ARCHITECTURE.md に入れるべき内容
6. issue / TODO に変換すべき内容
7. ブログ化できる主張
8. 思想カード化できる断片
9. 捨ててよい一時文脈

出力形式:
- 残すもの
- 捨てるもの
- 送信先
- 次の1手
