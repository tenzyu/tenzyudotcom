# @tenzyu/ui-react

`@tenzyu/ui-react` keeps root exports focused on foundations and publishes
components through subpath entries such as `@tenzyu/ui-react/button`.

Component stories are colocated with their implementation. This `src/stories`
area is reserved for foundations, composed patterns, and visual regression
checks that span multiple components.
