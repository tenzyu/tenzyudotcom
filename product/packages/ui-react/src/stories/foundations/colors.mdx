# Colors

Color tokens are provided by `src/index.css` and should be consumed through
semantic token classes such as `bg-background`, `text-foreground`, `bg-primary`,
and `text-muted-foreground`.

Use semantic tokens in stories so light and dark mode checks exercise the same
surface area as package consumers.
