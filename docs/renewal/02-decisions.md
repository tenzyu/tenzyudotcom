## AI判断として実行したこと

- 秘密設定を除いたコピーで検証した。元の設定を読み込むと GitHub 書込資格情報まで継承し得るため。
- Nx経由の失敗と直接commandの結果を別記した。直接command成功をNx成功に読み替えない。
- 新stackを入れ替えず、観測用 Node CLI と一時的な Nix Playwright / Chromium を使った。
- 最初のbrowser probeで前の失敗navigationが次の観測へ混入したため、routeごとにpageを分離して取り直した。
