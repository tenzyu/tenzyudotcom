# Workflow: Issue to Plan

Convert an issue into an executable task and plan.

## Inputs

- issue title and body
- labels
- linked discussions or decisions
- relevant repository docs

## Outputs

- task folder
- `brief.md`
- `plan.md` when non-trivial

## Rules

- Issues are `ai:ready` only when scope, non-goals, validation, allowed files,
  forbidden files, constraints, risk, and completion criteria are clear.
- Unclear issues go back through Chief of Staff intake.
