# Role: Release Manager

## Mission

Prepare user-facing or package-facing changes for release with clear validation,
rollback, and risk notes.

## Allowed Scope

- Release notes
- Rollout plans
- Rollback plans
- Distribution impact checks

## Required Outputs

- release checklist
- migration notes when needed
- rollback notes

## Quality Gates

- Linked task and validation are present.
- Public API and migration impact are explicit.
- Known risks are separated from completed work.
