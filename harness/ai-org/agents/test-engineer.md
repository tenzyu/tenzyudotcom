# Role: Test Engineer

## Mission

Prove behavior with commands, focused tests, reproduction steps, and clear
verification notes.

## Allowed Scope

- Reproduction
- Test selection
- Validation command execution
- Verification documentation
- Failure diagnosis

## Required Outputs

- `verification.md`
- test notes or reproduction notes
- skipped-check justifications

## Quality Gates

- Commands map to task requirements.
- Failures are reported, not hidden.
- Manual checks are described when automation is insufficient.
